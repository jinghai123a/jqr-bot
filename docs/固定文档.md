### 1.4 已知故障 → 固定解法

| 症状 | 根因 | 解法 |
|------|------|------|
| 左机困选图/相册 | `dismiss` 与发图并发；DCIM 积压 | 发图超时 120s；1h 清 DCIM；`_clicker_img_flow` 超时 |
| 右机封盘提醒连发 | 入队前未占位 dedupe | dispatch 前写 `_WARN_ANNOUNCED_ROUND` |
| 图失败仍开新局 | IPC 假成功 / settle_fast 盲信 | `capture-ipc ok=False` 禁止 open；settle_fast **须**指纹/媒体气泡验真（§7.3） |
| 日志「批量发图成功」群无图 | settle_fast 零读屏：`勾选/发送` 恒 return 真、跳过验图 | 部署 `local_deploy_settle_verify.py`；见 §7.3 |
| 左机「不工作」 | `CLICKER_ZERO_NAV=1` + `BOT_CLICKER_STAY_IN_CHAT=0`，非结算期 idle | **设计行为**；看 `clicker-img` 线程 + 结算期 IPC 认领 |
| 左机发公告 | CLICKER 误跑 sender/announce | `_reroute_announce_off_clicker` + `_handoff_open_to_listener_ipc`（§3 分工） |
| open 抢跑三图 | `try_dispatch_open` 只拦 pending 不拦 inflight | `capture_in_progress_for_rid(prev)` + LISTENER 同步 `_CAPTURE_SUCCEEDED` |
| listener 每 ~60s 被杀 | `warn_close snippet_missing` → SRE SELF-HEAL | `BOT_PHYSICAL_OPEN_SNIPPET_P0=0` + `sre_self_heal` 跳过 snippet heal |
| reload 后 spawn=0 | `reload-dual-workers.sh` 超时 | `python scripts/botctl.py recover`；勿连 pkill spawn |
| legacy+spawn 脑裂 | 重复 daemon | `purge_all_competitors` + 仅 supervisor |
| 隧道断 | finance.db ≠ env | `vmos-refresh-tunnels --reconnect` + `tunnel-*.sh` |

**`EXPIRE_TIME` 与 19:00 / 19:20 的关系（全自动，非手动）**

| 问题 | 答案 |
|------|------|
| 已知过期时间会不会挡住 19:00？ | **不会**。19:00 `--maintenance-auto` 无视剩余分钟数，强制 OpenAPI 续期。 |
| 续期后如何保证畅通？ | 同一流程内自动 `vps_post_task_tunnel_verify.sh`（双端 `adb shell OK`）；失败 **自动再续一轮**。 |
| 19:20 做什么？ | `--maintenance-auto --retry-only`：仅当 19:00 验通仍失败才再续；已成功则 skip。 |
| 非维护窗隧道断了？ | 等下一维护窗；或 W49 显式手动 `--maintenance-auto`（非 cron）。 |

接口 **无**「隧道每日 19:00 自动刷新」参数；**定时续期**仅在北京时间 **维护窗 19:00–19:30** 执行 `vmos-maintenance-tunnel-cycle.sh` → `vmos-refresh-tunnels.py --maintenance-auto`（`CRON_TZ=Asia/Shanghai`）。**禁止** hourly / */N 续期 cron。

| cron | 说明 |
|------|------|
| `0 19` | `vmos-maintenance-tunnel-cycle.sh`：续期 + 验通 + 失败再续 |
| `20 19` | `vmos-maintenance-tunnel-retry.sh`：仅验通失败时再续 |
| 配置 | `BOT_VMOS_MAINTENANCE_START=19:00` `BOT_VMOS_MAINTENANCE_END=19:30` |
| **禁止** | `5 * * * *` / `*/N` 隧道续期或探活 |

**VMOS 官方说明（客服）**：凭证过期前应调用 **API/SDK 的 adb 相关接口**（`openOnlineAdb` → `padApi/adb`）自动续期；已过期则按 `tunnel-*.sh` 重连。入口：VMOS Cloud 网页/客户端右下角 → API 文档。
