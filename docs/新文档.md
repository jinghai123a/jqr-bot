## 8. 55M 界面特征库（全局 · 一次性归档）

> **机器可读**：`config/55m-knowledge/ui-pages.json` + `bot_ops/nav_guard.py`  
> **检测实现**：`bot_55chat_daemon.py` → `describe_screen_context` / `is_target_group_surface`  
> **原则**：特征只在此处维护；改检测逻辑须同步本节 + `nav_guard.py`，**禁止口头零散提醒**。

### 8.1 术语（必读）

| 词 | 含义 |
|---|---|
| **群聊页** `target_group` | 抬头 `群名 (人数)` + 底部 `输入消息`；**已在群内，禁止回群导航** |
| **回群** | 从错页/列表/桌面 **拉回** 目标群聊；**不是退群** |
| **退群** | 离开群会话；机器人 **禁止**（左机群聊内禁止 header 返回） |
| **大退** | `am force-stop` 杀进程后立刻 `am start`；**仅升级弹窗** |
| **温启动** | `am start -f 0x20000` REORDER_TO_FRONT；日常拉起，避免冷启动弹升级 |
| **Home 圆点** | VMOS 底栏黑条中间圆点 `KEYCODE_HOME`；回桌面 **保活进程** |
| **连环 Back** | 系统返回键连按 → 「再按一次退出程序」→ **禁止** |

### 8.2 页面类型全表（`describe_screen_context.page`）

| page | 识别特征（UI 文字 / Activity） | 右机 LISTENER | 左机 CLICKER |
|---|---|---|---|
| `target_group` | 抬头 `^.+\(\d+\)$` 如 `苍井空测试 (9)` + `输入消息`；Activity `GroupChatActivity` | 读屏/公告 b64/回复；**零导航** | 仅发图链；**禁止 header 退群** |
| `message_list` | 大标题 `消息` + 顶栏 `搜索` + 底栏 Tab（消息/通讯录/通话/我） | ZERO_NAV 下可 **点群名 1 次** 进群 | heal 前：消息 Tab → 点群名 |
| `wrong_chat` | 有 `输入消息` 但抬头 **非** 目标群 | 禁止发公告；单次 Back 出会话 | 同 |
| `search` | `支持搜索联系人` / `群别名` + `取消` | 点 **取消**；禁止盲 Back | 同 |
| `secret_key` | `加密密钥` / `秘密聊天加密密钥` | header 返回 | 同 |
| `group_settings` | `群成员`+`删除并退出`（≥2 命中） | 单次系统 Back | 同 |
| `webview` | `28.run` / `luck h5` / `加拿大28` / `开奖网`（且无 `输入消息`） | 关网页/点完成；**禁止点升级** | 拉回群聊 |
| `profile` | `添加好友` / `通过验证` | ADD 点头像链 | ADD 链 |
| `other` | 桌面/文件管理/System Tools/侧拉抽屉等 | 温启动或大退重进（仅升级） | `launch_messenger` |

### 8.3 叠加层 / 弹窗 / Toast（非独立 page，但阻断发送）

| 类型 | 识别特征 | 正确处理 | 错误处理（已禁用） |
|---|---|---|---|
| **升级弹窗** | `发现新版本` + `立即升级`；resource-id 含 `fullPopupContainer` / `tvUploadCommit` | **大退一次马上重进** `force_restart_messenger` | ~~点立即升级~~ ~~Back 关~~ |
| **退出 Toast** | `再按一次退出` / `再按一次退出程序` | **禁止再 Back**；点群名或 **Home 圆点** | ~~连环 Back~~ |
| **侧拉抽屉** | `打开侧拉抽屉` / `Open navigation drawer` | **单次 Back** 关抽屉 | ~~连环 Back 退桌面~~ |
| **转发提示层** | `最近转发` / `快速分享` | 点底栏 **消息** Tab 刷新 | — |
| **左机杂弹窗** | `强制更新` / `安全密码` / `要退出` | 点 `稍后`/`取消`/`知道了` | 不 force-stop |
| **PopupWindow/IME** | dumpsys 焦点含 `PopupWindow` / `InputMethod` | ESC 收起键盘 | — |
| **桌面/文件管理** | `System Tools` / `文件管理` / `Chrome` / `Downloads` | 温启动 55M | monkey 冷启动（末手段） |
