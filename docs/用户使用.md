## 〇、性能铁律（最关键）

下列三类对外行为，目标均为 **毫秒级**（从系统收到触发到群聊 **OUT 气泡可见** 或结算图发出）：

| 类别 | 触发 | 毫秒级要求 |
|------|------|------------|
| **用户指令回复** | 群内合法指令/下注 | 读屏识别 → 生成回复 → 发送，全链路 **毫秒级** |
| **公告发送** | 封盘前 70s / 15s 窗、三图后新一局 | 进入时间窗后 **立即** 发出，不得拖到秒级以后 |
| **结算发图** | 28.run 公布开奖后 | 采集 → 成图 → 连发三图 → 新一局文字，**第一时间毫秒级** 完成 |

- 验收：**群聊 OUT 气泡/图片时间戳** 为准，不是日志 PASS。  
- 开发优先级：任何优化、重构、选型，先问「能否缩短上述三条链路延迟」；框架与 env 为达标服务，不为旧文档守成。  
- 维护窗 **18:56–19:32** 除外。

| 顺序 | 时机 | 群内内容 |

| 2 | 三图发完后 | **新的一局开始**（§4.3 正文，含期号与指令说明） |

### 3.2 六合彩

| 玩法 | 赔率 / 限额 |
|------|-------------|
| 特码 1–49 | **46 倍**；单注 5–1500 |
| 大小单双 | 大/单 1.84，小/双 1.91；限额 20–10000 |
| 组合 | 大单 3.5；大双/小单/小双 3.8 |
| 合单/合双 | 1.84 / 1.91 |
| 生肖 | 马 9.2；其余 11.5 |
| 波色 | 红 2.7；蓝/绿 2.87 |
| 头 | 0 头 5.1；1–4 头 4.6 |
| 尾 | 0 尾 11.5；1–9 尾 9.2 |
| 五行 | 金木 4.6；水 5.1；火 3.8；土 5.7 |

**六合规则要点**
- **冠军** = 特码 **头**：0–4 直取；5→0 头、6→1 头、7→2 头、8→3 头、9→4 头。  
- **亚军** = 特码 **尾** 0–9。  
- **保本**：遇 **5-0** 或 **0-0** → 退本，不输不赢，**不算流水**。

### 3.3 通用免责

- **线上有效，线下无效**；一切以 **机器人核对栏（控制面板）** 为准；未经核对一律无效。  
- 若 **官网已开奖** 而群内机器人尚未封盘，此间下注 **不予赔偿**（只吃不赔）。  
- 封盘前可自行 **扣取消** 或撤回消息取消错单；格式错误、输错自负。
