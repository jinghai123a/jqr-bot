# 固定文档 · 全局线程与资源分发

> **性质**：双脑 daemon 并发架构固定说明（W49 2026-06-24）。  
> **用途**：改性能、抢锁、队列、读屏前 **先读本文件**；与 `docs/固定-公告顺序与内容文本.md` 配套。  
> **原则**：各功能独立线程；争抢点拆成 **资源 1–4**，互不踢皮球。  
> **完成标准**：见 `固定-公告顺序与内容文本.md` §0——双机云机按 §2 预定线路实机跑通，且 **§0.2 第 7 项**：双机时刻在真正工作（在群、线程活跃、非误屏挂机）。

---

## 1. 设计目标

| 问题 | 方案 |
|------|------|
| dump 与 tap 抢 ADB | 读屏唯一入口 + fire 专用 tap 线程 |
| sender / clicker-img 互 re-enqueue | 每 serial 独立 outbound 堆队列 |
| 用户指令被公告堵住 | 优先级：CMD > 公告 > 结算图 > 结算文 |
| 首包 dump 慢 | ui-collect 预热 + 缓存 TTL 命中即返 |

## 2. 四大资源（固定）

```
┌─────────────────────────────────────────────────────────┐
│ 资源 1  ui-collect-{serial}                             │
│   唯一 uiautomator dump；缓存 root/snapshot；50ms 唤醒   │
├─────────────────────────────────────────────────────────┤
│ 资源 2  outbound_for(serial)                            │
│   每机一条优先级堆队列；sender / clicker-img 只消费      │
├─────────────────────────────────────────────────────────┤
│ 资源 3  listener-fire-{port}                            │
│   右机：仅 adb tap 发送键 (674,1234)，零 dump            │
├─────────────────────────────────────────────────────────┤
│ 资源 4  clicker-fire-{port}                             │
│   左机：发图链 + / 图片 等热 tap，零 dump                │
└─────────────────────────────────────────────────────────┘
```

### 资源 1 · UI 收集器

- 线程名：`ui-collect-{adbPort}`
- 类：`_UiResourceCollector`
- 规则：
  - 所有 `ui_hierarchy` / `ui_snapshot`（非 ui-collect 线程内）→ 入队 job → worker 批量 dump → fan-out
  - **缓存命中**（`UI_CACHE_TTL`）直接返回，不 dump
  - `_wake` 事件 **50ms** 聚合突发读屏
- 预热：`ui_collector_prewarm` 启动后后台采 listener + stay 快照

### 资源 2 · 出站队列

- 类：`OutboundQueue`（heapq，`(prio, seq, job)`）
- 每 **ADB serial** 一条队列（右 bot-4、左 bot-3 各一）
- 消费者：
  - 右机 **`sender-{botId}`**
  - 左机 **`clicker-img-{botId}`**（仅 image job）
- **防踢皮球**：job 失败/让路时 `outbound_enqueue` 回队，不在 sender 与 clicker-img 间互相丢

### 资源 3 · 右机 fire

- 线程名：`listener-fire-{port}`
- 队列：`SimpleQueue` of `_ListenerFireTap`
- 入口：`listener_fire_send_tap` / `listener_tap_pinned_send_now`
- **禁止**：dump、点输入框、导航

### 资源 4 · 左机 fire

- 线程名：`clicker-fire-{port}`
- 入口：`clicker_fire_tap` / `clicker_fire_attach_image`
- **禁止**：与读屏 dump 同线程串行 tap

## 3. 业务线程一览（VPS daemon）

| 线程 | 机器 | 职责 | 争抢资源 |
|------|------|------|----------|
| `listener-{id}` | 右 | 读屏、指令、热路径回复 | 资源 1 + 2 + 3 |
| `sender-{id}` | 右 | 消费 outbound 文字/（非左机图） | 资源 2 + 3 |
| `announce-{id}` | 右 | 封盘提醒/封盘公告定时检测 | 资源 1 → 入队 2 |
| `settle-{id}` | 右 | 28.run 结算检测、入队图+文 | 资源 1 → 入队 2 |
| `listener-stay-{id}` | 右 | 驻群看门狗（仅 Back 关 webview） | 资源 1 |
| `clicker-{id}` | 左 | ADD / 认人 / BIND 慢任务 | 资源 1 + 4 |
| `clicker-img-{id}` | 左 | 结算 batch 发图 | 资源 2 + 4 |
| `clicker-stay-{id}` | 左 | 驻群看门狗 | 资源 1 |
| `brain-refresh` | VPS | 配置/用户快照 | 无 ADB |
| `log-worker` | VPS | 异步写面板 log | 无 ADB |
| `adb-heal` | VPS | 隧道/ADB 自愈 | 无 UI |

**左机不发文字公告**；`announce` / `settle` 内 `is_clicker_bot` 直接 return。

## 4. 出站优先级（数字越小越先）

| prio | 常量 | 用途 |
|------|------|------|
| 0 | `SEND_PRIO_CMD` | 用户指令回复 |
| 1 | `SEND_PRIO_BRAIN` | 大脑排队回复 |
| 2 | `SEND_PRIO_TOPUP` | 上下分通知 |
| 10 | `SEND_PRIO_WARN` | 封盘提醒 |
| 11 | `SEND_PRIO_CLOSE` | 封盘公告 |
| 12 | `SEND_PRIO_OPEN` | 开局（若启用） |
| 19 | `SEND_PRIO_CAPTURE` | 左机结算三张图 |
| 20 | `SEND_PRIO_SETTLE` | 结算文字（代码遗留；**固定公告顺序已不含**，对齐时以公告固定文档为准） |
| 21 | `SEND_PRIO_TREND` | 走势图 |
| 22 | `SEND_PRIO_OPEN_AFTER_SETTLE` | 结算后「新的一局」 |

**让路规则**（sender 线程）：

- 左机 `capture_batch` 执行中，若右机 pending 公告文字 → 发图 job 短暂 re-enqueue（0.03s），避免图挡文字。
- 用户 `CMD` job 存在时，非公告类低优 job 让路。

## 5. 结算入队顺序（代码层 · 对齐固定公告文档）

固定公告顺序：**左三张图全部出队 → 右「新的一局」**（禁止先发文字再发图，禁止发开奖文字）。

1. `settle` 线程：`generate_settle_capture_paths` 顺序 **[流水, 六合, PC28]** → `capture_batch`（prio 19）→ 左机 `clicker-img`
2. 左机 `clicker-img`：`_push_images_to_gallery` 在 `newest_at=top` 时 **逆序 adb push**，顶行勾选左→右 = 群聊图序
3. 左机 batch **完成（成功或失败）** 后：`open`（prio 22）→ 右机 `sender`
4. **禁止** 入队 `settle` 开奖文字（prio 20）；**禁止** 新期 +10s 单独 `process_round_open_announce`（维护恢复除外）

## 6. 关键环境变量（资源/线程开关）

```bash
BOT_SEND_QUEUE=1              # 启用 outbound 资源 2
BOT_UI_COLLECTOR=1            # 启用 ui-collect 资源 1
BOT_LISTENER_SEND_MODE=adb_b64
BOT_LISTENER_TRUST_SEND=1     # 右机信任 fire，少验 draft
BOT_LISTENER_SEND_TAP_ONLY=1  # 右机只 fire 点发送
BOT_IMG_PINNED=1              # 左机钉死坐标
BOT_IMG_SEND_MODE=ui          # 左机 UI 批量发图
BOT_SETTLE=1
BOT_CLICKER_SEND_IMAGES=1     # 结算图委派左机
```
